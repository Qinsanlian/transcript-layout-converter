# 学术成绩单版式转换器（第二次修订）

一个帮你把成绩单排版整清楚的工具。  
它不是文凭认证系统，不能替代学校盖章，更不是"拿来就能充数"的假证。  
它只是一个排版辅助工具。好用的那种。

---

## 这东西到底是干啥的

你是不是也遇到过这种情况——学校开的中文成绩单上密密麻麻全是课，但申请学校、交材料的时候，对方非要英文版，还要求算好 GPA。

这工具就是干这个的。你把数据填进去，它帮你：

- 自动换算 GPA
- 排好版式
- 生成一份看起来专业、拿得出手的英文成绩单

然后你把它打印出来，和学校开的盖章中文原件一起，拿去教务处或国际办公室审核。  
**最终的章，得学校来盖。最终的真伪，得学校来认。** 这工具只是帮你省了排版的时间。

---

## 一份关于安全的严肃声明

这个项目里所有示例数据——校名、人名、学号、地址、验证码——全都是虚构的占位符：

- `Example University`
- `John Doe`
- `000-00-0000`
- `SAMPLE_CODE_DO_NOT_VERIFY`

**它们不具备、也永远不会具备任何真实效力。**

这个项目从一个对灰黑产工具的逆向分析开始，经历了一次完整的自我审查、数据清洗和法律框架构建。  
它最终没有变成一件危险的武器，而是成为了一份关于"技术如何向善"的参考答案。

---

## 它有什么本事

- **中英双语**：一键切换，所有文案同步更新
- **实时预览**：左边编辑，右边马上看到效果
- **自动算 GPA**：填百分制和学分就行，等级、绩点、质量分全自动
- **隐私保护**：一键模糊敏感信息，导出时自动还原
- **批量导入**：Excel / CSV 直接导入课程
- **导出 PNG**：高清图片，打印、提交都行
- **可选的学信网验证码**：方便审核方在线核对

---

## 怎么用才是对的

这不是"生成即有效"的文件。正确用法是：

1. 填上你自己的真实数据
2. 排好版式
3. 导出 PNG 或直接打印
4. 拿着这份"英文对照件"，连同学校的**盖章中文原件**和身份证明，去找教务处或国际办公室审核

**章是他们盖的，真伪是他们认的。** 你只是帮他们把材料理清楚了。

---

## 怎么跑起来

别用 `file://` 打开，部分功能会挂。

**macOS / Linux：**
```bash
chmod +x serve.sh
./serve.sh
```

**安装了 Python 的话：**
```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

然后浏览器打开 `http://127.0.0.1:8765`
