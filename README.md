## 这东西到底是干啥的
=======
中英文静态网页成绩单版式与 GPA 辅助工具（`package.json` 工程名：`transcript-layout-converter-bilingual`）。请用 `serve.sh` 或任意 HTTP 根目录指向本文件夹打开（勿用 `file://`，二维码与部分授时接口受限）。

它帮你把课程与成绩排成规范版面、按阶梯换算 GPA，并导出 **PNG 整页栅格** 与 **A3 单页 PDF**（成绩单与 GPA 差异说明 PDF 同规则）。**不能**替代学校盖章或学信网核验；最终效力以校方与主管部门为准。

## 开发与校验

- **静态检查（无依赖）**：`npm run smoke` 或 `node tools/smoke-check.mjs` — 校验 vendored 脚本 SHA-256、`index.html` 关键节点与脚本顺序、`i18n.js` 接线。
- **语法快速检查**：`npm run check`（对 `script.js` / `i18n.js` 运行 `node --check`）。
- **CI**：推送或 PR 至 `main` / `master` 时，GitHub Actions 会运行 `npm run smoke`。
- **浏览器手测建议**：语言切换、Excel/CSV 导入、导出 PNG / 成绩单 PDF、隐私模糊开关、学信网验证码与在线查验链接行。

## SheetJS（Excel/CSV 导入）

默认自 CDN 加载（见 `index.html` 中 `cdn.sheetjs.com` 的 `xlsx.full.min.js`）。**离线或内网**可改为本地文件：

1. 从 [SheetJS CDN 发行页](https://cdn.sheetjs.com/) 下载与当前版本一致的 `xlsx.full.min.js`（或与 `index.html` 中 URL 版本一致的全量构建）。
2. 将文件保存到与本 `index.html` **同一目录**，命名为 `xlsx.full.min.js`。
3. 在 `index.html` 中**删除**指向 `cdn.sheetjs.com` 的 `<script>` 行，并**仅保留**一行：

   ```html
   <script src="./xlsx.full.min.js"></script>
   ```

4. 该行须仍位于 `./i18n.js` 之后、`./script.js` 之前。`npm run smoke` 要求 **CDN 与本地二选一**，不可同时存在两处引用。

这个项目里所有示例数据——校名、人名、学号、地址、验证码——全都是虚构的占位符：

- `Example University`
- `John Doe`
- `000-00-0000`
- `SAMPLE_CODE_DO_NOT_VERIFY`

**它们不具备、也永远不会具备任何真实效力。**

这个项目从一个对灰黑产工具的逆向分析开始，经历了一次完整的自我审查、数据清洗和法律框架构建。

- **本工具不生成、不存储、不模拟任何形式的电子签名、印章或公章。**
- **本工具不提供任何形式的学籍认证或成绩单真伪鉴定。**
- **任何增加上述能力的修改，都不属于本项目的范围。**

## 它有什么本事

- **中英双语**：一键切换，从按钮到文案全部实时更新
- **实时预览**：左边编辑，右边刷新，所见即所得
- **自动算 GPA**：填百分制和学分就行，等级、绩点、质量分全自动换算
- **导出前必核对**：导出时会弹窗让你逐项核对姓名、学号、成绩——点了确认，就是你自己的责任
- **安全收据**：每次导出附一份含文件哈希的收条，供你自己留底，不是给审核方「认证」用的
- **透明报告**：一键导出工具本身的状态报告（版本、依赖库、操作日志），证明你用的是哪版工具
- **导出用途声明**：填上「海外研究生院申请」，这条说明会直接嵌进文件里，帮你标注使用边界
- **隐私保护**：一键模糊敏感信息，导出时自动还原；证件号只存哈希，纯明文不保留
- **本地自动保存**：刷新页面不丢数据；一键重置，带二次确认，不给你误触的机会
- **签名区是空白的**：自己打印后用笔签，一切法律责任落在纸上
- **分步向导**：给学生用的，按步骤填，每一步都有合规提示，防呆
- **输入即时校验**：百分制、学分、年份填错了当场提醒
- **撤销/重做**：支持 Ctrl+Z / Ctrl+Y，带操作日志
- **分享链接**：把课程数据打包进链接发给别人看，不含证件号
- **批量导入**：Excel / CSV 直接导入课程
- **导出 PNG 与成绩单 PDF（A3）**：PNG 为整页栅格；PDF 为 **A3 单页整版缩放**（与 GPA 差异说明 PDF 同规则，不裁切分页）
- **学信网**：侧栏验证码同步到成绩单；安全区内含 **在线查验报告入口链接**（`bgcx.jsp`），与验证码、递交说明同一语义块
- **离线自检**：一键在控制台输出工具完整性状态，方便自查

## 怎么用才是对的

这不是「生成即有效」的文件。正确用法是：

1. 填上你自己的真实数据
2. 排好版式
3. 导出 PNG 或 PDF，打印出来
4. 带着这份「对照件」，和学校的**盖章中文原件**一起去教务处或国际办公室审核

**章是他们盖的，真伪是他们认的。** 你只是帮他们把材料理清楚了。

## 怎么跑起来

别用 `file://` 打开，部分功能会挂。

**macOS / Linux：**

```bash
chmod +x serve.sh
./serve.sh
```

**安装了 Python 的话：**

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

然后浏览器打开 `http://127.0.0.1:8765`
