本项目帮助你将课程数据整理成一份结构清晰、版式专业的英文成绩单，以便于提交给海外院校或作为非正式参考。

## 核心特性

-   **中英双语**：一键切换页面语言，所有文案（包括安全声明、GPA阶梯、课程表头）同步更新。

## 正确的使用流程

**这不是一份“生成即有效”的文件。** 正确的使用流程应是：

1.  **填写真实数据**：在此工具中，根据你学校出具的 **官方盖章成绩单原件**，填入你自己的真实信息。
2.  **调整版式**：确保信息完整、清晰，并确认页面用语。
3.  **导出为PNG**：点击“导出成绩单为 PNG”按钮。
4.  **作为辅助对照件提交**：将导出的、带有你个人数据的这份 **“辅助对照件”** ，连同你学校出具的 **盖章中文原件** 及其他身份证明材料，一并提交给你所在的学校教务处、国际办公室或接收方。**最终的权威认定，必须由他们做出。**

## 快速开始

**重要提示：请勿使用 `file://` 协议打开页面，否则部分功能（如二维码、网络授时）将无法使用。**

**方法一：使用 serve.sh (macOS / Linux)**
```bash
chmod +x serve.sh
./serve.sh
```
然后在浏览器中打开 `http://127.0.0.1:8765` 即可。

**方法二：使用 Python**
```bash
# 在项目根目录下执行
python3 -m http.server 8765 --bind 127.0.0.1
```
同样，在浏览器中打开 `http://127.0.0.1:8765` 即可。

**方法三：使用任何静态文件服务器**
将项目文件夹指向你的静态服务器根目录，然后访问对应的 `index.html`。

### SheetJS 离线配置

1. 从 [SheetJS CDN](https://cdn.sheetjs.com/) 下载 `xlsx.full.min.js` 到项目根目录。
2. 在 `index.html` 中，将指向 CDN 的 `<script>` 标签替换为本地引用：
   ```html
   <script src="./xlsx.full.min.js"></script>
   ```
3. 本地引用依然需要位于 `./i18n.js` 之后、`./script.js` 之前。
